🛍️ Site Santa Lolle

Este projeto usa recursos do site da marca Santa Lolla, desenvolvido com fins educacionais para praticar habilidades em desenvolvimento web, como HTML, CSS e JavaScript.

📌 Sobre o projeto

O objetivo deste projeto é reproduzir a interface de um e-commerce moderno, focando em:

Layout responsivo
Estruturação semântica
Estilização com CSS
Interatividade com JavaScript
Boas práticas de desenvolvimento front-end

⚠️ Este projeto não possui fins comerciais. Todos os direitos de design pertencem à marca original.

🚀 Tecnologias utilizadas
HTML5
CSS3
JavaScript
💻 Funcionalidades
Página inicial com vitrine de produtos
Layout inspirado em e-commerce real
Navegação entre seções
Interface moderna e responsiva
